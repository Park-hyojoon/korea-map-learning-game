# 한반도 지형 암기 게임

한반도 지도에서 우리나라 주요 도시의 위치와 특징을 게임처럼 익히는 웹 학습 도구입니다.

## 시연하기

[웹에서 바로 학습하기](https://park-hyojoon.github.io/korea-map-learning-game/)

## 학습 범위

여덟 개 권역, 52개 도시를 담고 있습니다. 권역 탭으로 골라 학습합니다.

| 권역 | 도시 |
|---|---|
| 강원도 | 춘천, 강릉, 평창, 원주, 삼척, 영월, 태백 |
| 경상북도 | 경주, 대구, 안동, 포항, 울릉도, 문경, 울진, 의성 |
| 전라남도 | 순천, 광주, 보성, 목포, 여수, 영광, 신안, 광양 |
| 경남·제주 | 창녕, 울산, 부산, 통영, 창원, 고성, 거제, 하동, 제주 |
| 경기·서울 | 고양, 의정부, 서울, 수원, 용인 |
| 충남·대전·세종 | 대전, 세종, 천안, 아산, 서산, 당진, 태안, 보령 |
| 전라북도 | 전주, 군산, 김제, 남원, 무주 |
| 충청북도 | 청주, 단양 |

## 시험보기

권역 탭 옆의 `📝 시험보기`를 누르면 전국 52개 도시에서 무작위로 출제됩니다.

- 풀고 싶은 문제 수를 **8개에서 40개까지** 직접 정할 수 있습니다.
- 시험 중에는 여덟 권역이 모두 지도에 색으로 나타나고, 포인트도 전부 보입니다.
- 다 풀면 권역별로 몇 개 맞고 몇 개 틀렸는지 표로 보여 줍니다.
- **가장 많이 틀린 권역**을 알려 주고, 그 권역을 바로 복습하러 갈 수 있습니다.
- 시험 기록은 브라우저에 쌓여서, 다음에 시험보기를 열면 그동안의 권역별 누적 성적을 볼 수 있습니다.

## 주요 기능

- 도시 특징을 읽고 지도 위 위치 선택
- 초성 힌트, 정답·오답 피드백, 점수와 연속 정답 표시
- 마우스 휠 또는 두 손가락 핀치로 지도 100~250% 확대·축소
- `−` `+` 버튼으로 25%씩 단계 확대·축소
- `⊞ 전체 지도` 버튼으로 100% 보기 복귀
- 확대 상태에서 `Space`를 누른 채 마우스로 끌어 이동, 휴대전화는 한 손가락 드래그
- 확대 배율에 따라 `?` 아이콘 크기가 함께 변경
- 휴대전화에서 권역을 고르면 지도로 바로 이동하고 그 권역이 확대되어 가운데 표시
- 학습 중이거나 완료한 권역만 원색, 나머지 권역은 회색 표시
- 완료한 권역은 브라우저에 기록되어 탭에 체크 표시
- 휴대전화와 컴퓨터 화면 모두 지원

## 로컬에서 실행하기

`index.html`과 `KakaoTalk_20260829_172706236.jpg`를 같은 폴더에 둔 뒤 `index.html`을 브라우저로 열면 됩니다.

## 도시 위치 조정

`index.html`의 `GAME_REGIONS.<권역>.cities` 배열에서 각 도시의 `x`, `y` 값을 바꾸면 됩니다. 두 값은 지도 너비와 높이에 대한 퍼센트 좌표입니다.

```js
{
  city: "춘천",
  x: 47.8,
  y: 15.5
}
```

`x`가 커지면 오른쪽, `y`가 커지면 아래쪽으로 이동합니다.

`cover`는 지도에 인쇄된 도시명을 가리는 판입니다. `width`는 지도 너비 대비 퍼센트, `aspect`는 가로÷세로 비율입니다. 지도에 이름이 적혀 있지 않은 도시는 `cover: null`로 두면 가림판을 만들지 않습니다.

작업 배경과 좌표를 뽑은 방법은 [HANDOFF.md](HANDOFF.md)에 정리해 두었습니다.
