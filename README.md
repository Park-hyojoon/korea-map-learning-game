# 한반도 지형 암기 게임 — 강원도 테스트

한반도 지도에서 강원도 주요 도시의 위치와 특징을 게임처럼 익히는 웹 학습 도구입니다.

## 시연하기

[웹에서 바로 학습하기](https://park-hyojoon.github.io/korea-map-learning-game/)

## 현재 학습 범위

- 춘천
- 강릉
- 평창
- 원주
- 삼척
- 영월
- 태백

## 주요 기능

- 도시 특징을 읽고 지도 위 위치 선택
- 초성 힌트, 정답·오답 피드백, 점수와 연속 정답 표시
- 마우스 휠로 지도 확대·축소
- `⊞ 전체 지도` 버튼으로 100% 보기 복귀
- 현재 학습 권역인 강원도만 원색, 나머지 권역은 회색 표시
- 휴대전화와 컴퓨터 화면 모두 지원

## 로컬에서 실행하기

`index.html`과 `KakaoTalk_20260829_172706236.jpg`를 같은 폴더에 둔 뒤 `index.html`을 브라우저로 열면 됩니다.

## 도시 위치 조정

`index.html`의 `GAME_REGIONS.gangwon.cities` 배열에서 각 도시의 `x`, `y` 값을 바꾸면 됩니다. 두 값은 지도 너비와 높이에 대한 퍼센트 좌표입니다.

```js
{
  city: "춘천",
  x: 47.8,
  y: 15.5
}
```

`x`가 커지면 오른쪽, `y`가 커지면 아래쪽으로 이동합니다.
